# Iris Species Classification using Neural Network

## Name
Sushanth N Prabhu

## Project Overview
This project implements a neural network from scratch using NumPy to classify iris flowers into three species:
- Iris-setosa
- Iris-versicolor
- Iris-virginica

## Features Used
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Neural Network Architecture
Input Layer: 4 neurons  
Hidden Layer 1: 10 neurons (ReLU)  
Hidden Layer 2: 5 neurons (ReLU)  
Output Layer: 3 neurons (Softmax)

Architecture:
4 → 10 → 5 → 3

## Concepts Implemented
- Data Loading
- One-Hot Encoding
- Normalization
- Forward Propagation
- Cross Entropy Loss
- Backpropagation
- Gradient Descent

## Final Accuracy
~93% to 96%
